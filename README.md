# Window 3.11

Recriação independente da área de trabalho do Windows 3.11, em português, escrita em HTML, CSS e JavaScript. Ícones desenhados em Canvas. Licença Apache-2.0.

Abra `index.html` ou sirva a pasta com `python3 -m http.server 8080` e visite `http://localhost:8080`. A execução dispensa instalação de pacotes e serviços externos. Use a mesma origem para manter acesso aos documentos salvos.

O Gerenciador de Programas reúne os grupos Principal, Acessórios e Jogos. As janelas suportam movimentação, redimensionamento, minimização e maximização. O menu Janela alterna entre programas abertos.

O disco virtual guarda textos e desenhos em localStorage. Limpar os dados do site apaga esses arquivos. O prompt interpreta comandos internos como DIR, TYPE e CLS. A implementação reproduz a interface no navegador e não executa binários Win16 ou DOS. O conjunto de programas é parcial. Não inclui componentes da Microsoft.
